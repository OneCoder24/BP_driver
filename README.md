# SCAPE Bin-Picking Controller

Драйвер и GUI для управления роботом в задаче бин-пикинга (bin-picking). Связывает адаптер SCAPE с промышленным роботом через TCP-протокол, предоставляет интерфейс для калибровки, ручного управления (джоггинг) и автоматического пикинга.

## Структура проекта

| Файл | Описание |
|---|---|
| `driver_gui.py` | Главный GUI-контроллер (Tkinter). Запуск, управление режимами, логи |
| `driver.py` | Протокольный слой драйвера (uplink/downlink с адаптером) |
| `config.py` | Конфигурация подключений, состояния, перечисления |
| `task_executor.py` | Исполнитель задач — реестр обработчиков команд адаптера |
| `user_logic.py` | Пользовательская логика post-pick действий |
| `jogging_panel.py` | Панель ручного управления роботом (джойстик, схват, скорости) |
| `debug_window.py` | Отладочное окно |
| `collect_points.py` | CLI-скрипт для интерактивного сбора точек через джойстик |

## Зависимости

- Python 3.12+
- `scipy` — конвертация ориентаций (Euler angles)
- `API` — проприетарный SDK робота (поставляется отдельно)

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python driver_gui.py
```

## Режимы работы

- **Калибровка** — последовательная калибровка сочленений робота
- **Пикинг** — автоматический цикл: запрос детали → движение → захват → укладка
